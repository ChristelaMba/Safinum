# Tester SAFINUM

## Avec l'extension (recommande : marche sur n'importe quel site)
1. Ouvrir l'adresse de demonstration et cliquer sur **Telecharger l'extension SAFINUM**.
2. Decompresser le fichier. Dans Chrome ou Edge : `chrome://extensions` (Edge : `edge://extensions`), activer le **mode developpeur**, **Charger l'extension non empaquetee**, choisir le dossier `safinum-extension`.
3. Ouvrir un site web (une banque de demonstration, par exemple), cliquer sur l'icone SAFINUM, **J'accepte**, puis **Pidgin** ou **Fulfulde**.

L'extension est deja reglee sur le serveur de demonstration : aucune adresse ni cle a saisir. La langue reste active d'une page a l'autre. **Arreter** remet la page comme avant.

## Sans rien installer
Sur la page d'accueil, **Ouvrir la banque de demonstration** : SAFINUM y est deja actif.

A observer : montants, frais et noms identiques ; champs de mot de passe et de code jamais lus ; voix pour les messages importants ; aucune action automatique ;
en cas de doute, l'original apparait entre parentheses.
